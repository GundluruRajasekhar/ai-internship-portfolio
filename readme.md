## What this is

A single scannable page: hero summary → four project cards with links and
tech tags → skills gained → certificate details → contact. It's meant to
sit alongside (not replace) the narrated project dossier — this one is
built for a recruiter skimming in 30 seconds, the dossier is built for
someone who wants the longer, spoken walkthrough.

## Deploying to GitHub Pages

1. Create (or reuse) a public GitHub repository.
2. Add `index.html` to the repository root (or a `/docs` folder).
3. In the repo's **Settings → Pages**, set the source branch/folder and save.
4. GitHub publishes the page at `https://<username>.github.io/<repo>/`.
